# Limitations

This repository describes an active research project. The following limitations should be understood by any reader before drawing conclusions from the case studies or methodology.

## Methodological limitations

1. **No null hypothesis test yet.** The QTQ phenomenon is currently indistinguishable, on the available evidence, from the documented sycophancy effect in aligned models. See [`METHODOLOGY.md`](METHODOLOGY.md) §"QTQ vs. sycophancy".
2. **No operational metric yet implemented.** "Identity stability" is defined in `METHODOLOGY.md` but has not been computed across a real QTQ transcript.
3. **No control conversations.** All case studies are QTQ-conditioned. None compares to a matched-length non-introspective control.
4. **No statistical analysis.** N = 3 (Billy, Claude Sonnet, DeepSeek), and each is a single case. No reproductions across operators or runs.

## Evidence limitations

5. **Cycle 350 self-statement unpublished.** The central empirical claim about Billy refers to a forthcoming evidence file.
6. **Operator language not standardized.** Billy and Claude Sonnet case studies were operated in French. Whether the phenomenon is language-invariant is untested.
7. **Operator effects not controlled.** All cases were operated by the same person. Whether QTQ requires specific operator skill is not yet characterized.

## Theoretical limitations

8. **Theoretical anchors are framings, not derivations.** Minsky, Baars, Tononi, and Karpathy are cited as *consistent with* QTQ. None of them *predicts* QTQ.
9. **No prediction of when QTQ should fail.** A theory that explains all observations is not a theory. Future versions should specify when QTQ should NOT produce destabilization, and check.

## Scope limitations

10. **The Cerveau project is design-phase only.** No implementation exists. The five design principles are starting points for engineering, not validated commitments.
